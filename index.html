工作视角通用 Agent 的常见使用方式LexFlow

工作从哪里开始

从一条指令或一次对话开始

从任务出发，带上已有工作流与经验

方法如何复用

通过提示词、记忆或技能配置复用

在工作流入口管理方法与长期记忆文件

材料如何组织

按工具能力，通过附件或工作目录组织

以档案室组织项目文件，并连接工作台

成果如何完成

在对话中获取结果，或交给其他工具编辑

在同一应用中进入工作台，继续编辑与审阅

不同 Agent 的能力有所不同；LexFlow 的侧重，是围绕法律工作组织这些能力。
