帮助

安装、使用与模型接入的完整说明。帮助内容分为四个部分：安装说明、使用说明、模型接入与常见问题。

1安装说明

LexFlow 适用于 Apple 芯片的 Mac（M1、M2、M3、M4 及之后），系统要求 macOS 12 或更新版本。点击左上角苹果菜单 →「关于本机」，可以看到芯片与系统版本。

点击下方按钮下载安装包。文件较大，下载时间取决于网络情况。

适用于 Apple 芯片的 Mac

打开下载完成的安装包，把 LexFlow 图标拖入「应用程序」文件夹。

首次打开需要额外一步。LexFlow 未经过 Apple 公证（本项目系开源项目，暂无盈利，Apple 公证需 688 元/年，因而暂未开通），首次打开时系统会拦截，提示「无法打开，因为 Apple 无法检查其是否包含恶意软件」。这是未公证应用的正常提示，按下面的步骤放行即可。

  1. 在提示框中点击「完成」。不要点「移到废纸篓」。
  2. 打开「系统设置」，进入「隐私与安全性」，向下滚动到「安全性」一栏。
  3. 找到「已阻止使用"LexFlow"」，点击「仍要打开」，输入开机密码确认。
  4. 再次双击 LexFlow，在弹出的窗口中点击「打开」。

首次启动后，按应用内的提示完成模型服务配置（见下方模型接入），之后即可开始使用。上述步骤只需做一次，之后从「应用程序」或程序坞中直接打开即可。

LexFlow 是开源软件，源代码发布在 GitHub（github.com/LexFlowApp/LexFlow）。

2使用说明

LexFlow 围绕三个核心概念组织您的工作：工作流、长期记忆与档案室。它们都存放在您指定的知识库文件夹中。

工作流——写清了某类工作如何一步步完成的文档。把反复出现的工作（例如合同审阅要点梳理、案件事实整理）的做法写成工作流，之后在对话中点名使用，LexFlow 会按其中的步骤执行，结果稳定可复现。工作流可以设为「仅手动使用」「相关时自动使用」或「新会话自动加载」。

长期记忆——先零散保存下来的内容。不需要事先想清楚结构，随手记下的事实、偏好、进度都会存入知识库，之后可在对话中被检索使用；内容成熟后可以转为工作流。

档案室——存放案件或项目原始材料的地方。把需要引用的文档（合同、证据清单、研究报告等）放入档案室，在对话中即可让 LexFlow 读取和引用，与讨论内容互不混杂。

知识库完全保存在您的电脑本地。工作流、长期记忆与档案室都是普通的本地文件夹与 Markdown 文本文件，不上传到任何服务器；在设置中选择另一个文件夹，即可随时把整个知识库迁走，或接入其他人工智能工具继续使用。您对自己的数据拥有完整的控制权。

新建或导入内容：在「工作流」区域点击右上角加号，可以创建工作流或长期记忆，也可以点击「导入」把已有的 Markdown 文件加入知识库。

3模型接入

LexFlow 不内置模型，需要接入模型服务商后使用。打开「设置 → 模型」，选择服务商并填入密钥即可。主流服务商的接入方法如下：

DeepSeek——访问 DeepSeek 开放平台（platform.deepseek.com）注册并创建 API 密钥，在 LexFlow 的 DeepSeek 卡片中粘贴密钥即可，国内访问稳定，推荐作为首个接入的服务商。

GLM（智谱）——访问智谱开放平台（open.bigmodel.cn）获取 API 密钥，在 GLM 卡片中粘贴。LexFlow 同时支持智谱国内 API 与其编程套餐通道。

GPT（OpenAI）——访问 OpenAI 平台（platform.openai.com）创建 API 密钥，在 GPT 卡片中粘贴；已有 ChatGPT 订阅的用户也可以走 Codex 订阅通道接入。

Kimi（月之暗面）——支持两种官方方式：其一为「API 调用」，访问 Kimi 开放平台（platform.moonshot.cn）创建密钥，在 API 卡片中粘贴，按用量计费；其二为「套餐」，月之暗面官方提供的 Kimi 编程套餐（Kimi For Coding）会员接口，订购后在套餐卡片中填入密钥，两种方式均为官方支持。

MiMo（小米）——访问小米 MiMo 开放平台获取 API 密钥，通过「添加自定义服务商」接入：填写 API 协议（OpenAI 兼容）、API 地址与模型 ID。

任何其他兼容 OpenAI 接口的服务商（如本地部署的模型、中转服务等）都可以通过「添加自定义服务商」接入，只需填写 API 协议、API 地址、密钥与模型 ID。

常见问题

为什么会出现「无法验证开发者」或「已损坏」的提示？

macOS 默认只允许打开经过 Apple 验证的应用。LexFlow 未加入 Apple 开发者计划（本项目系开源项目，暂无盈利，Apple 公证需 688 元/年，因而暂未开通），因此没有经过公证，首次打开需要按上面第 1 部分的步骤手动放行。应用本身可以正常使用。

放行之后还安全吗？

安全。LexFlow 已经在 GitHub（github.com/LexFlowApp/LexFlow）上完全开源，全部源代码公开可查，任何人都可以审查应用实际做了什么。

LexFlow 是一款完全的本地应用：知识库、工作流与档案室等数据都保存在您自己的电脑上，应用本身不设任何服务器、不上传任何信息；应用涉及的联网服务只有模型对话，而模型服务商由您自行选择和配置，连接的都是 DeepSeek、GLM、Kimi 等第三方模型的官方接口。因此 LexFlow 本身不存在信息窃取等问题。

建议只从本站或 GitHub 仓库获取应用，不要使用来路不明的安装包。

我的电脑是 Intel 芯片的 Mac，可以安装吗？

暂不支持。目前的安装包仅适用于 Apple 芯片的 Mac。

iPhone、iPad 上可以用吗？

不可以。LexFlow 是 macOS 桌面应用，没有手机版本。

我的数据会被上传吗？

知识库（工作流、长期记忆、档案室）完全保存在本地。对话内容仅发送给您自己配置的模型服务商用于生成回复，LexFlow 不设任何中间服务器。

如何迁移或备份我的知识库？

直接拷贝知识库文件夹即可。更换电脑或重新安装后，在设置中重新选择该文件夹，全部工作流、长期记忆与档案室内容原样恢复。

LexFlow 出了 bug 怎么解决？

您可以先向 LexFlow 自己提出问题，让它尝试定位并解决，也可以请其他 agent 帮您排查，通常这是最快的解决方式。

您也可以把问题反馈到 LexFlow 邮箱 lexflow@yeah.net，我们会尽快为您解决。
